## 接线候选与剩余验证

正在实现独立的 `source_kind=official_command_exec` 记录。原 A 作为 Store 准入者，owned 官方 CLI 作为实际命令执行器。此协议没有模型 thread/turn/item；`processId` 只在连接内路由，不能当作 OS PID，也不能填入旧的原会话回执契约。

新候选在派发前保存固定命令和准入，接收同一连接的真实终态后保存事实；未知结果不重派，暂停或授权变化只允许回收。直接在开发树运行时，旧发行清单正确拒绝变动后的宿主摘要；失败保留。隔离副本按准确源码重建清单后，66 项相关测试通过。候选仍待原 B 独立审核和同次真实受限验证器联测，不能据此称 Host→Store 已验收。

CLR 静态指令相符不能证明运行时修改合法。TLS 分配状态、GC 可变输入、完整系统映像、JIT 与正式回执仍未认证。r62 的空配置目录不等于环境变量已清除凭据，后续执行入口还需核对实际环境。Hyper-V 限制与官方 Windows token sandbox 是不同边界，未把普通流式命令的生命周期结果推广到后者。

本轮未更改安装副本、原窗口配置、trust、活动桥或活动 pair 数据库；仅提交本记录及关联进展链接。诊断源码、内存快照、凭据和未审核产品改动未纳入这次提交。
