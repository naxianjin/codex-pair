## 本轮修复

1. Windows 审计校验器补充原生句柄读取辅助器，并纳入发行必需项、安装清单和校验契约的 reader 摘要。实际覆盖中文/非 BMP、超过 260 字符路径、祖先 junction、软/硬链接、活动写句柄、超过 5 MiB 的文件及非法 UTF-8。保留原上游资产，未降低 POSIX 校验条件。
2. Windows 兼容性预检使用无子进程的系统信息查询；没有预检记录的新执行绑定明确拒绝。审核控制器在启动回合前后固定执行、任务及实际 CLI 来源，避免只有直接 Python API 可用。
3. 显式手动交接不再被 CLI 专属投递预检错误阻断；暂停、恢复、审核、资源和额度门禁保留。
4. 暂停时拒领尚未派发的普通消息，保留已有结果、对账和检查点的读取收尾。新增交付读取、确认、完成且不触发新派发的回归。
5. 范围收尾保存任务快照。旧任务、未知目标和自动规划保持关闭；新登记任务的审核、审批、恢复应用和执行绑定使用准确任务关联。新范围需要重新确认辅助池及额度等授权，不能继承旧范围的忽略额度记录。
6. 修正 SQLite 连接未关闭、夹具写源码旁目录、旧检查契约遗漏、审核回读替身不完整、Windows 路径大小写比较、元数据替身类型及恢复后未调用真实调度等问题。额度周期用例改为明确构造新周期；原生产周期绑定算法未因该伪失败被改写。

首次完整回归为 883 个唯一测试通过、59 个非通过、3 个跳过。失败记录保留，未用后续通过覆盖历史。跨代理静态复核曾发现范围修复未贯通审核/应用、辅助额度授权继承等问题，修正后再复核和动态验证；静态复核不能代替正式工具回执审核。
