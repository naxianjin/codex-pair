# CLI 0.167.0-alpha.3.2 生产者适配候选

本轮将准确版本 `0.167.0-alpha.3.2` 加入现有严格生产者契约。当前原生 CLI 的 SHA256 为 `4b3286e35d7fe866c6b0eb3f07d7a4cdb5e96489576170dfd6b3a15aa1c67382`，实际 `--version` 与该版本相符。

原官方会话 `01a1b0ae-5e37-7c80-812b-9953f2b0371f` 的准确回合 `01a1b3b9-a1d2-7161-81f2-6dd928105d3a` 提供了 10 个实际 commandExecution。只读 API 展示与原账号持久日志中的 argv 经现有正向引用编码后逐项相等，目录、来源、终态和退出码也一致。测试夹具只替换了本地目录及工具项 ID，保留真实字段形状与引用形式；完整本机证据不发布。

另启动同一原生 CLI 的只读元数据 app-server 子进程，实际验证文件身份、进程创建时间、读取准确原会话、结束前再次核验及退出后拒绝旧 PID。该进程没有创建、恢复或执行模型会话。此结果验证受管子进程跟踪接口，不能证明原可见窗口的工具生产者来源。

普通与优化模式各 27 项准入及版本回归通过。覆盖单来源拒绝、未知或邻近版本拒绝、目录/来源/退出码/argv 冲突，以及既有生命周期门禁。新增版本仍要求完整 `VerifiedProducer`、准确执行绑定和结束核验；版本字符串、模型身份或格式匹配均不能单独放行。

当前为候选，须对准确文件独立复审。宿主正式工具认证、可信加载内容、JIT 认证及正式 Store 结算仍为 `needs_validation`。
